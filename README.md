# Mr. Crabs — Аркадная игра

Мобильная Android-игра: управляй крабом и уворачивайся от падающих кокосов. Чем дольше продержишься — тем выше счёт.

---

## Как это работает

1. Кокосы падают сверху в случайных позициях с нарастающей скоростью
2. Тянешь краба влево или вправо касанием экрана
3. Кокос упал на землю — **+10 очков**
4. Кокос попал в краба — **−1 жизнь**
5. Потерял все 3 жизни — игра окончена, показывается финальный счёт

---

## Функции

- **Управление касанием** — плавное перетаскивание краба по экрану
- **Анимированные кокосы** — покадровая анимация из 3 кадров
- **Взрывы** — анимация из 4 кадров при ударе кокоса о землю
- **Система жизней** — индикатор меняет цвет: зелёный → жёлтый → красный
- **Счёт** — отображается в реальном времени, кастомный шрифт Kenney Blocks
- **Фоновая музыка** — играет на протяжении всей игры
- **Экран настроек** — отдельный Activity
- **Game Over** — экран с итоговым счётом и кнопкой рестарта

## Стек

### Платформа
- Android (minSdk 24)
- Java

### Рендеринг
- Кастомный `View` с `Canvas` — без сторонних игровых движков
- `Handler` + `Runnable` — игровой цикл с интервалом 30 мс (~33 FPS)
- `Bitmap` / `Rect` — отрисовка спрайтов и фона

### Ресурсы
- Покадровые PNG-спрайты (кокос, взрыв, краб, фон)
- Кастомный шрифт `.ttf` (Kenney Blocks)
- Фоновая музыка `.mp3`

---

## Игровая логика

Столкновение краба с кокосом проверяется через пересечение прямоугольников (`Rect`) каждые 30 мс. При столкновении кокос сбрасывается в случайную позицию, жизнь уменьшается. При `life == 0` запускается `GameOver` Activity с передачей очков через Intent.
